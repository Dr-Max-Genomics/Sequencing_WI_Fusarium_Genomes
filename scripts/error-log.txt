Title: Offline OrthoFinder + MMseqs2-GPU (Apptainer/Singularity) on Atlas (SCINet)
Author: Maxwell Chibuogwu
Last updated: 2026-09-30

SUMMARY
-------
This guide installs and runs OrthoFinder v3.1.5 with MMseqs2-GPU inside an Apptainer container on Atlas (SCINet), fully OFFLINE on compute nodes. We stage artifacts on the login node (which has WAN), then build the container on a GPU compute node without WAN, and run OrthoFinder with CUDA via --nv.

Key ideas:
- Apptainer should be run from a COMPUTE node on SCINet (use salloc/srun). 【1-ad28ac】
- Runtime access to GPUs requires Apptainer’s `--nv` flag (binds /dev/nvidia* and host CUDA libs). 【2-1eec85】
- Bind project directories with `-B` to access data inside the container. 【3-1b1b03】
- Offline builds: stage Miniconda + Python wheels + MMseqs2-GPU tar via `%files`, then `pip install --no-index --find-links` in `%post`. 【3-1b1b03】【4-13d3fd】


PREREQUISITES
-------------
Paths (adjust if needed):
- Project base:  /project/silage_microbiome/orthofinder
- Artifacts dir: /project/silage_microbiome/orthofinder/container_assets
- Local Ubuntu base SIF: /project/silage_microbiome/orthofinder/ubuntu.sif
- Apptainer binary (bypass broken module on compute nodes):
  /apps/spack-managed-x86_64_v3-v1.1/gcc-11.5.0/apptainer-1.4.3-gjmkxcehl4zeatqaag3ukwzmb75g77xz/bin/apptainer

Note: SCINet’s container guidance emphasizes using Apptainer from compute nodes, obtained via `salloc`, and binding datasets when running. 【1-ad28ac】

TROUBLESHOOTING
---------------
- “destination /project/ doesn’t exist” during build:
  Create bind destinations in `%setup` (e.g., /project, /90daydata, /reference). This is how system binds are handled in Apptainer. 【3-1b1b03】

- WAN timeouts on compute node:
  Compute nodes often block outbound WAN; build offline by staging artifacts on the login node. 【1-ad28ac】

- Modulefile errors with Apptainer module on compute nodes:
  Use the absolute Apptainer binary path without loading the module; SCINet allows Apptainer from compute nodes; binds and --nv still work. 【1-ad28ac】

- Cross‑platform pip wheel downloads:
  Use `pip download --platform manylinux2014_x86_64 --python-version 312 --only-binary=:all:`; build missing wheels locally (pip wheel) with a py312 conda env. 【4-13d3fd】
